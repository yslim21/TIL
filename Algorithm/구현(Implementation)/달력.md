# 달력
[달력](https://www.acmicpc.net/problem/20207)

## 개념
+ 가로 길이: 그 구간이 며칠 이어지는지
+ 세로 높이: 그 구간 안에서 동시에 겹친 일정의 최대 개수
+ calender 배열 만들기
  + 각 날짜마다 일정 몇개인지 count하기 (calender[day])
+ calender 배열 돌면서(1일부터 365일까지돌면서)
  + 값이 0이 아니면 현재 연속된 일정 진행 (0이면 연속된 일정이 끊긴것)
    + 길이 width++
    + 높이 height는 calender[day]값 중 최대값으로 갱신

+ *calender 배열이 366이 아니라 367인 이유는 마지막 연속된 일정도 count하기 위해서(반복문상 366으로 하면 12/31까지 연속된 경우는 answer에 안더해지고 끝남)

## 풀이
```java
import java.util.*;
import java.io.*; 

public class Main{
    public static void main(String[] args)throws Exception{
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        int N = Integer.parseInt(st.nextToken());
        
        int[] calender = new int[367];
        
        for(int i =1; i <=N; i++){
            st = new StringTokenizer(br.readLine());
            int s = Integer.parseInt(st.nextToken());
            int e = Integer.parseInt(st.nextToken());
            
            for(int day=s; day<=e; day++ ){
                calender[day]++;
            }
        }
        
        int answer =0; 
        int width=0; 
        int height =0; 
        
        for(int day=1; day <=366; day++){
            if(calender[day] >0){
                width++; //최대 며칠 이어지는지 
                height = Math.max(height, calender[day]); // 몇번 일정 겹치는지 
            }else{ //일정이 끊길때
                answer += width*height;
                width=0;
                height =0; 
            }
        }
        System.out.println(answer);
    }
}
```
